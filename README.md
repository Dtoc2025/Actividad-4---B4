# Actividad 4 - B4

Mini app que consume una API pública (JSONPlaceholder) usando fetch() y muestra los datos con un filtro de búsqueda.

## Estructura
- index.html
- style.css
- script.js
- eslint.config.mjs
- .husky/pre-commit

## Instalación
1. Clonar el repositorio.
2. Ejecutar `npm install`.
3. Abrir `index.html` en el navegador.

## Herramientas
- ESLint: análisis estático.
- Husky: pre-commit hook que ejecuta `npx eslint .` y bloquea el commit si hay errores.
